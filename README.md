## 🌌 Overview

**Oma AI Agent** is a next-generation PC companion that bridges real-world Windows automation with a **PC in 2070** cybernetic interface. Oma orchestrates your apps, windows, screens, files, and deep web research through an intelligent multi-agent virtual workplace.

---

## ✨ Features

### 1. 🔮 3D Holographic Neural Sphere
- Real-time WebGL/Canvas 3D particle sphere rotating in space with orbital gyroscopic rings.
- Dynamic states: `SYSTEM ACTIVE`, `THINKING...`, `LISTENING...`, `EXECUTING`.
- Audio-reactive frequency pulsation responding to speech input and voice synthesis.

### 2. 🧠 Neural Mind Map
- Live capability nodes:
  - **Memory:** Saved preferences, past history, and persistent facts.
  - **Skills:** Real Windows automation tools (`winctl`), DuckDuckGo web search, screen vision, bash commands.
  - **Soul:** Natural conversational persona with voice synthesis.
  - **Setting:** Global push-to-talk hotkey (`Ctrl + Alt + Space`), toggle keys, and model parameters.
- Animated glowing cyber cables with data pulses flowing into the central core.

### 3. 🏢 Agent Town (2D Pixel Art Virtual Office)
- 2D pixel art workplace simulator with dual-monitor developer desks, conference room, server racks, and break lounge.
- Autonomous AI units:
  - **Alice (Senior Researcher):** Web research, fact synthesis, report writing.
  - **Bob (System Architect):** PowerShell / Bash automation, code compiling.
  - **Carol (Automation Specialist):** Windows snapping, multi-monitor layouts, app launch.
  - **Dave (Creative & Comm):** Text synthesis, summaries, notifications.
- **Dynamic Task Dispatching:**
  - Tasks dispatched from user voice/text cause agents to react with thought bubbles (`💡`, `!`), walk to their desks, and display dynamic speech bubbles showing real-time task progress.

### 4. 🎙️ Voice & Agent Live Feed
- Real-time conversation stream with speaker labels and audio waveform bars.
- Live module chips: `[module: research_web]`, `[module: open_bash_panel]`, `[module: window_control]`.
- Text-to-Speech synthesis in Urdu, Hindi, and English.

## 🚀 Quick Start

### 1. Launch the Cybernetic Interface
Simply double-click:
```bat
start.bat
```
or run from terminal:
```bash
python server.py
```
This opens the dashboard at:
👉 **`http://localhost:8765`**

### 2. Run with Oma CLI
```bash
# Launch futuristic UI
python oma.py --ui

# One-off command
python oma.py "what's on my screen?"

# Free web search
python oma.py --search "latest breakthroughs in quantum computing"

# Move/arrange windows
python oma.py --place chrome left current + wt right current
```
